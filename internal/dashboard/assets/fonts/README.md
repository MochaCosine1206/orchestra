# Dashboard Font Assets

Variable WOFF2 fonts for the Orchestra dashboard.

## Source

Google Fonts — https://fonts.google.com/

Downloaded via the Google Fonts CSS API v2 with woff2 format selection.

## Files

| File | Family | Weight Range | Source |
|------|--------|-------------|--------|
| `manrope-variable.woff2` | Manrope | 200-800 | https://fonts.google.com/specimen/Manrope |
| `space-grotesk-variable.woff2` | Space Grotesk | 300-700 | https://fonts.google.com/specimen/Space+Grotesk |
| `inter-variable.woff2` | Inter | 100-900 | https://fonts.google.com/specimen/Inter |
