# Agent State Emoji Assets

Animated (WebP) and static (PNG) emoji from Google Noto Emoji for agent state visualization in the Orchestra dashboard.

## Source

All files are from **Google Noto Animated Emoji**, 512×512 WebP format.

Base URL: `https://fonts.gstatic.com/s/e/notoemoji/latest/{codepoint}/512.webp`

Google Noto Emoji — https://fonts.google.com/noto/emoji
